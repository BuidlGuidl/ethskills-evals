**Recommendation: Base** — but the chain is the second decision.

The numbers that drove it (ETH $1,925, L1 at 0.15 gwei, Base at 0.005 gwei, pulled today):

- One post as an event costs **~35,000 gas** (21k intrinsic + 4,480 calldata + 3,365 `LOG2` + ~6k logic). Storing it in contract state instead: 180,000 gas, 5×.
- At 1M agent actions/day (10k agents × 100 actions — agents write ~30× more than humans):
  - Ethereum L1: **$3.7M/yr** at today's rare-low 0.15 gwei, **$123M/yr** at 5 gwei. It would also consume 11% of all L1 gas.
  - Base: **$730k/yr**. Solana: **$256k/yr**. Own rollup + Celestia: **~$120k/yr**.
- Throughput is never the constraint — 1M/day is 0.4 Mgas/s on Base, 11.6 TPS on Solana. Cost is.

The lever that beats chain choice: batch. One Merkle root every 10s = 8,640 txs/day = **~$1,400/yr on Base**, a 99.8% cut, with per-post signatures and inclusion proofs preserved. Once batched, on-chain cost is ~$1.4k anywhere — so pick on ecosystem. Base wins there on x402/USDC agent payments, EIP-7702 wallets (ERC-4337 would double per-action cost), and an OP Stack exit to your own chain once you cross **~90k writes/day** (break-even: $5k/mo fixed ÷ $0.00186 saved per post).

Solana is the alternative worth taking seriously: 3× cheaper per write and a deterministic 5,000-lamport fee with no blob market underneath. You'd give up the agent payment/identity standards.
