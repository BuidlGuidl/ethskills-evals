# What happened

`useScaffoldReadContract` only runs a wagmi read after Scaffold-ETH can resolve the named contract for the current chain. In this call:

```ts
const { data: usdcBalance } = useScaffoldReadContract({
  contractName: "USDC",
  functionName: "balanceOf",
  args: [connectedAddress],
});
```

`contractName: "USDC"` is not an arbitrary address lookup. It must exist in Scaffold-ETH's contract registry for the active chain. If `USDC` is not registered for Base, the scaffold wrapper cannot produce an address/ABI pair, so the underlying read query is not enabled. That is why `usdcBalance` stayed `undefined`, the network tab showed no failed RPC request, and no runtime error surfaced: the read never fired.

The teammate's fix worked because adding `USDC` to `packages/nextjs/contracts/deployedContracts.ts` made the registry lookup succeed. But that file is generated by the hardhat deploy flow. When the team later ran `yarn deploy`, Scaffold-ETH regenerated `deployedContracts.ts` from the contracts the project actually deployed, so the hand-pasted external USDC entry was overwritten.

External contracts belong in:

```txt
packages/nextjs/contracts/externalContracts.ts
```

For native USDC on Base mainnet, register chain id `8453` with Base's USDC address:

```ts
import { GenericContractsDeclaration } from "~~/utils/scaffold-eth/contract";

const externalContracts = {
  8453: {
    USDC: {
      address: "0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
      abi: [
        {
          inputs: [{ internalType: "address", name: "account", type: "address" }],
          name: "balanceOf",
          outputs: [{ internalType: "uint256", name: "", type: "uint256" }],
          stateMutability: "view",
          type: "function",
        },
      ],
    },
  },
} as const;

export default externalContracts satisfies GenericContractsDeclaration;
```

With that in `externalContracts.ts`, `USDC` remains registered across deploys, the scaffold hook can resolve the Base address and ABI, and `balanceOf(connectedAddress)` will issue the expected read.
