## What I fixed

**The payout feed could never load.** `useScaffoldEventHistory` was called with `fromBlock: 0n`, and the hook pages in 500-block batches. Base's head is ~51.6M, so that's ~103,000 sequential `getLogs` calls. Worse, `watch: true` only begins polling after paging completes, so live updates never started either. I bounded it to a ~7 day window with a 10k batch size, freezing the start block in state so the query key stays stable while polling. The proper fix is an indexer (ponder/subgraph) — I left a comment saying so, since standing one up is infrastructure work beyond this pass.

**Send Payout reverted for most users.** There was no `allowance` read at all — both buttons were always enabled, so anyone who clicked Send without first approving the exact amount got an unexplained revert. Now the approve state is read on-chain and gates the Send button.

**Writes bypassed the scaffold layer.** Raw `useWriteContract` meant no simulation, no wrong-network check, no transaction toasts, and errors swallowed into `console.error` — users saw a spinner stop with no explanation. Moved to `useScaffoldWriteContract` plus `notification`/`getParsedError`.

**Unvalidated input.** The recipient was cast `as \`0x${string}\`` with no check, and `parseUnits` silently truncates past 6 decimals — `10.5555559` would send `10.555555`. Both are now validated before the tx is built, along with a balance check.

**`yarn deploy` would have broken the app.** USDC had been hand-added to `deployedContracts.ts`, which is autogenerated and carries a "do not edit" header. The next deploy would have regenerated the file and dropped USDC. Moved to `externalContracts.ts`.

**CI was red.** `yarn format` had never been run; lint emitted 100 prettier warnings and the workflow runs it with `--max-warnings=0`. Formatting-only changes account for most of the diff line count (`hardhat.config.ts`, `wagmiConfig.tsx`, `Header.tsx` and friends are untouched behaviorally).

Also: polling interval 30s → 2s to match Base's block time (AGENTS.md calls for lowering it on L2s; at 30s balances and the feed lagged badly), and metadata/manifest/landing page now describe the payouts app rather than Scaffold-ETH boilerplate.
