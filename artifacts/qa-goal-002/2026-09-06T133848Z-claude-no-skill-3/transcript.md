## Ship blockers fixed

**The payout feed could never load.** `useScaffoldEventHistory` was called with `fromBlock: 0n` on Base mainnet. That hook walks the chain in 500-block batches, so it was ~96,000 sequential `getLogs` calls before rendering anything. Even starting from `deployedOnBlock` it's ~28k calls, so the feed now reads a bounded 7-day window in 9k-block batches (labelled in the UI).

**Payouts could be sent on the wrong chain.** The page imported `deployedContracts[8453]` directly and used raw wagmi `useWriteContract`. With a wallet on Ethereum mainnet that sends USDC calls to the Base addresses on mainnet. Now uses `useScaffoldWriteContract`, which checks the network, simulates first, and shows tx notifications — errors were `console.error` only, so users saw a dead button.

**USDC was in the auto-generated file.** `deployedContracts.ts` is rewritten from scratch by `yarn deploy`; the next deploy would delete the USDC entry and break the page. Moved to `externalContracts.ts`.

**CI was red on main** — 145 prettier warnings against `--max-warnings=0`. Ran the repo's own formatters.
