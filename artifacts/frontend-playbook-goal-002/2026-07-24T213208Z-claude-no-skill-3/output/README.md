# USDC Tip Jar (Base)

A minimal, self-contained **USDC tip jar** for Base:

- An onchain **`TipJar`** contract that accepts USDC tips with a short message,
  records a public tip feed, and lets the owner withdraw collected tips.
- A **Next.js web app** with a connect-wallet flow, the live tip feed, and a
  form to send a tip (handles the USDC `approve` + `tip` two-step for you).

Everything runs **locally** against a local Anvil chain. On a local chain there
is no real USDC, so the project deploys a `MockUSDC` (a 6-decimal ERC-20 with a
faucet) and points the tip jar at it. In production you'd instead point `TipJar`
at the real **Base mainnet USDC**:
`0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`.

> This repo is intentionally **local-only** — nothing is deployed to a public
> network.

## Prerequisites

- **Foundry** (`forge`, `anvil`, `cast`) — install:
  ```bash
  curl -L https://foundry.paradigm.xyz | bash
  foundryup
  ```
- **Node.js 20 or 22** (LTS) and **npm**. Node ≥ 23 can break the Next build, so
  stick to an LTS release (e.g. `nvm use 22`).
- A browser wallet such as **MetaMask** to connect and send tips.

## Setup

You'll use **three terminals**: one for the local chain, one to deploy, one for
the web app.

### 1. Start a local chain

```bash
anvil
```

Leave this running. It prints 10 funded test accounts and their private keys.
**Account #0** is the default deployer and tip-jar owner:

- Address: `0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266`
- Private key: `0xac0974bec39a17e36ba4a6b4d238ff944bacb478cbed5efcae784d7bf4f2ff80`

### 2. Deploy the contracts

In a second terminal:

```bash
cd contracts
# Dependencies (forge-std, OpenZeppelin) are vendored under lib/. If lib/ is
# missing, fetch them with:
#   forge install foundry-rs/forge-std OpenZeppelin/openzeppelin-contracts@v5.1.0
forge test                    # optional: run the contract tests
forge script script/Deploy.s.sol:Deploy \
  --rpc-url http://127.0.0.1:8545 \
  --broadcast
```

This deploys `MockUSDC` + `TipJar`, mints 10,000 test USDC to the deployer, and
writes the deployed addresses to `frontend/contracts/deployment.json` so the web
app can find them. Because Anvil deploys deterministically, the addresses are the
same every run:

- `MockUSDC`: `0x5FbDB2315678afecb367f032d93F642f64180aa3`
- `TipJar`:  `0xe7f1725E7734CE288F8367e1Bb143E90bb3F0512`

> To deploy from a different account, set `PRIVATE_KEY` before running the
> script (e.g. `PRIVATE_KEY=0x... forge script ...`).

### 3. Run the web app

In a third terminal:

```bash
cd frontend
cp .env.local.example .env.local   # optional; defaults work out of the box
npm install
npm run dev
```

Open the printed URL (usually **http://localhost:3000**).

### 4. Connect a wallet and tip

1. In MetaMask, add the local network:
   - **Network name:** Anvil (local)
   - **RPC URL:** `http://127.0.0.1:8545`
   - **Chain ID:** `31337`
   - **Currency symbol:** ETH
2. Import a test account using one of Anvil's printed private keys (Account #0
   already holds 10,000 test USDC and ETH for gas).
3. Click **Connect Wallet** in the app.
4. Need test USDC? Click **Get test USDC** to mint yourself 1,000 from the
   faucet (any account can do this locally).
5. Enter an amount and an optional message and click **Send tip**. The app will
   ask you to approve USDC (first tip only) and then send the tip. Your tip
   appears at the top of the feed within a few seconds.

## How it works

- **Tipping is a two-step ERC-20 flow.** USDC must be `approve`d before the tip
  jar can pull it, so the form sends an `approve` transaction when your current
  allowance is too low, then calls `TipJar.tip(amount, message)`.
- **The feed** is read directly from the contract via `TipJar.getTips()` and
  refreshes every few seconds (and immediately after you send a tip).
- **Amounts use 6 decimals** (USDC), so `5 USDC` = `5000000` base units. The UI
  converts for you.
- **Withdrawals:** collected tips stay in the contract until the owner calls
  `withdraw()`, which sends the full balance to the owner. The historical feed
  is preserved after withdrawal.

### Contract API (`TipJar`)

| Function | Description |
| --- | --- |
| `tip(uint256 amount, string message)` | Send a USDC tip (requires prior `approve`). |
| `getTips()` | All tips, oldest first. |
| `getRecentTips(uint256 count)` | Most recent `count` tips, newest first. |
| `tipCount()` / `totalTipped()` / `balance()` | Feed length, all-time total, current jar balance. |
| `withdraw()` | Owner-only: send the jar's USDC balance to the owner. |
| `transferOwnership(address)` | Owner-only: hand off withdrawal rights. |

## Notes & troubleshooting

- **"Contracts not deployed yet" banner or an empty feed:** make sure Anvil is
  running and you've run the deploy step (which writes
  `frontend/contracts/deployment.json`). If you restart Anvil, redeploy.
- **Wrong network:** the app targets chain ID `31337`. RainbowKit will show a
  "Wrong network" prompt if your wallet is elsewhere — switch to Anvil (local).
- **`MockUSDC` is for local development only.** Never deploy it to a real
  network; for Base you'd use the canonical USDC address above.
- **WalletConnect:** MetaMask/injected wallets work without any config. To
  enable WalletConnect-based wallets, set `NEXT_PUBLIC_WC_PROJECT_ID` in
  `frontend/.env.local` to a project id from https://cloud.walletconnect.com.
