**Two things I'd check before building anything.** First, pull fifty real disputes and classify them: if they're mostly "your gateway dropped my submission" rather than arithmetic disagreements, this builds excellent arbitration for a question nobody asked. Second, `cargo build --target wasm32-unknown-unknown` on the routine as-is — if it needs a real port, the premise is gone. Both are cheap and either can invalidate the plan.
