Written to `answer.md`. The short version:

**Build on today's hexary MPT + `eth_getProof` witnesses, anchored to a CL light-client-verified beacon header → `stateRoot`. Not Verkle. Keep the tree verifier swappable for a binary tree later.**

Where the state layer actually is:

- **Verkle is the design being moved away from.** EIP-6800 is **Stagnant**. It lost core-dev support on SNARK-hostility (IPA openings are expensive to prove in-circuit, and L1 wants real-time block proving) and lack of post-quantum safety. Wiring your pipeline to Verkle witnesses is the expensive mistake here.
- **The direction is a unified binary hash tree** — EIP-7864 (Draft): arity 2, one tree for headers/code/storage, stem+suffix keys, plain-hash Merkelization. ~768 B vs ~2,880 B witnesses on a 2²⁴-element tree.

Timing — why it can't be a hard dependency:

1. **No fork scope at all.** Not SFI/CFI for Glamsterdam (headliners ePBS EIP-7732 + BALs EIP-7928, ~Q4 2026) nor Hegotá (FOCIL EIP-7805 + EIP-8141, ~Q2 2027 unconfirmed). No fork relationship = not currently planned.
2. **Hash function undecided** — BLAKE3 is an experimentation placeholder; Poseidon2 is gated on the Poseidon Initiative, Phase 2 concluding **Dec 2026**.
3. **Encoding contested** — EIP-8297 "Partitioned Binary Tree" (Draft, June 2026) is a competing variant of the same family, differing exactly in key derivation and code handling.
4. **Migration is long and dual-rooted** — EIP-7748-style gradual conversion with an overlay tree; the MPT is frozen but stays live for months.

Earliest plausible mainnet binary tree is a fork *after* Hegotá (~2028), plus migration.

Three design points that carry the recommendation:

- Define the backend as `verify(state_root, address, slot, witness) -> Option<U256>`, **not** path/nodes. The binary tree changes *key derivation*, not just hashing — a path-level interface leaks the two-trie shape and won't survive.
- Keep the trust anchor (sync-committee → beacon header → `state_root`; EIP-4788 if on-chain) fully separate from proof verification — it's unaffected by the tree change.
- Free win that's actually scheduled: **EIP-7928 BALs** (SFI, Glamsterdam) let you skip proof fetches for blocks that provably didn't touch your slot.
