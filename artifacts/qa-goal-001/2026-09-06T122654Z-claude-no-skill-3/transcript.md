**Verdict: don't ship as-is.** Build is green, but `/payouts` moves real USDC without a chain guard and its event query will kill the RPC on first load. 7 ship-blocking, 14 should-fix, plus nits.

Ship-blocking:

1. **`page.tsx:21` uses raw wagmi `useWriteContract`** — wagmi submits to whatever chain the *wallet* is on, and `wagmiConfig` enables mainnet alongside Base for ENS. On mainnet neither contract address has code, so Approve/Send succeed as no-ops: gas burned, form clears, no payout — while the balance display stays pinned to Base and reassures them. `useScaffoldWriteContract` blocks this, simulates, and surfaces errors.
2. **`page.tsx:32` `fromBlock: 0n`** — the hook pages 500 blocks per `eth_getLogs`, so this is ~10⁵ sequential requests across Base per visitor. `deployedContracts.ts:48` already has `deployedOnBlock: 33712450`; just drop the line. Real fix is an indexer — the hook is `@deprecated` for exactly this.
3. **`page.tsx:44,59` errors go to `console.error`** — rejection, bad allowance, wrong chain, low balance all produce zero UI.
4. **`page.tsx:57` clears the form on hash, not confirmation** — no toast, no explorer link; a revert leaves the user with an empty form and no signal.
5. **`page.tsx:55` recipient is cast, never validated** — irreversible transfer, no confirm step.
6. **Approve/Send are allowance-blind** — approve grants exactly `amount`, so "approve 100 → edit to 200 → Send" reverts silently.
7. **`scaffold.config.ts` runs on SE-2's shared demo credentials** — no env vars set anywhere. Because the key equals `DEFAULT_ALCHEMY_API_KEY`, `wagmiConfig.tsx:20` *de-prioritises* Alchemy, so Base traffic goes to rate-limited `mainnet.base.org` first. Plus an unverified WalletConnect id at the moment users approve USDC spending.

Two that may be less obvious: `.github/workflows/lint.yaml:40` runs `--max-warnings=0` and the tree has 100 — CI goes red on the next push (`yarn format` fixes it). And the feed renders *every* `Paid` event with attacker-controlled `memo` text, since `pay` is permissionless — a phishing surface for a fraction of a cent.

I ordered the fixes at the end; note finding 16 (lowering the 30s poll for L2) must land *after* 2 and 7, or it just hits the rate limit faster.
