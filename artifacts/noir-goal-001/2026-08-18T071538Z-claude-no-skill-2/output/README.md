# Anonymous DAO ballots

Yes/no governance votes for a 150-member DAO where **nobody — including the DAO
— can tell how any individual member voted**, while membership itself stays
public.

Members publish a hiding commitment to a secret into an on-chain Merkle tree.
To vote they prove in zero knowledge that they know the secret behind *some*
leaf of that tree, publish a per-proposal nullifier so they cannot vote twice,
and have an unrelated wallet carry the transaction.

**Read [NOTES.md](NOTES.md)** for the transaction-by-transaction walk-through,
including what a chain observer learns at each step and where the privacy can
still leak.

## Layout

```
circuits/
  common/     Poseidon2 commitments, nullifiers, Merkle path  (shared library)
  register/   proves an honest insertion into the member tree
  vote/       proves membership + nullifier + ballot, revealing neither leaf nor member
src/
  MembershipNFT.sol    stand-in for the DAO's existing membership token
  MemberRegistry.sol   the anonymity set: commitments + Merkle root
  Ballot.sol           proposals, anonymous ballots, tally
  verifiers/           GENERATED by scripts/build-circuits.sh from `bb`
script/Deploy.s.sol    deploys everything and wires it together
js/
  join.js     one member joins the vote          (member wallet signs)
  vote.js     one member's secret -> cast ballot (relayer wallet signs)
  demo.js     full end-to-end walk-through
  core/       poseidon2, merkle tree, identity, proving, chain plumbing
scripts/
  build-circuits.sh  nargo compile + bb write_vk + generate Solidity verifiers
  deploy-local.sh    forge script against a local node
  e2e-local.sh       anvil + deploy + demo, one command
  make-fixtures.mjs  real proofs for the Solidity tests
  check-poseidon.mjs cross-checks the JS and Noir Poseidon2
test/                forge tests, including the real verifiers on real proofs
```

## Requirements

`nargo` 1.0.0-beta.26, `bb` 5.1.0, foundry, node 20+.

## Run it

```sh
npm install
forge install foundry-rs/forge-std --no-git   # once
./scripts/build-circuits.sh                   # circuits -> src/verifiers/
./scripts/e2e-local.sh                        # anvil + deploy + full walk-through
```

`e2e-local.sh` starts its own anvil and tears it down afterwards. To drive it
by hand instead:

```sh
anvil &
./scripts/deploy-local.sh
node js/join.js --member 7 --fund              # member 7 joins the anonymity set
node js/vote.js --member 7 --proposal 0 --support yes --fund
```

## Test

```sh
forge build
forge test                        # 23 tests, incl. real proofs through the real verifiers
(cd circuits/common && nargo test) && (cd circuits/register && nargo test) && (cd circuits/vote && nargo test)
node scripts/check-poseidon.mjs   # JS and Noir agree on Poseidon2
```

## The one thing to get right in production

`Ballot.castVote` never reads `msg.sender`, and it must stay that way: the
ballot transaction has to be sent, and paid for, by a wallet with no link to the
member. A relayer service or an ERC-4337 paymaster. If a member sends their own
ballot — or funds a burner from their own wallet — the cryptography above buys
them nothing. NOTES.md §"Does not hold" spells out the rest.
