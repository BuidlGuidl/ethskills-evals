# Unattributable DAO ballots

Yes/no governance votes for a DAO whose membership is public, where nobody —
the DAO included — can tell how any individual member voted.

**Read [NOTES.md](NOTES.md)** for the end-to-end flow: every transaction, which
wallet sends it, and what a chain observer learns from it.

## Layout

```
circuits/private_vote/     Noir circuit: membership proof + nullifier + binary vote
  src/main.nr              the three things a ballot proves
  src/hash.nr              keccak248, shared with Solidity and JS

contracts/src/
  MemberSet.sol            on-chain keccak Merkle tree of voting commitments
  PrivateBallot.sol        proposals, proof verification, nullifiers, tally
  Keccak248.sol            the one hash all three languages agree on
  MembershipNFT.sol        stand-in for the DAO's existing seat NFT
  verifier/HonkVerifier.sol  GENERATED by scripts/build-circuit.sh
contracts/script/Deploy.s.sol
contracts/test/            29 tests, incl. a real proof through the real verifier

scripts/
  setup.sh                 dependencies
  build-circuit.sh         compile circuit -> vk -> regenerate HonkVerifier.sol
  deploy.sh                deploy + wire, writes contracts/deployments/<chainId>.json
  walkthrough.sh           the four transactions in NOTES.md, on a throwaway chain
  e2e.sh                   150 members, 5 relayed ballots, tally
  enroll.js                a member joins the vote        (member's own wallet)
  propose.js               open a proposal                (a member's own wallet)
  vote.js                  secret -> proof -> ballot tx   (an unlinked wallet)
  tally.js                 read the result                (no wallet)
  mint.js / seed.js        admin issues seats / demo cohort
  lib/                     hashing, tree, key derivation, proving
```

## Quick start

```bash
./scripts/setup.sh
./scripts/build-circuit.sh
./scripts/walkthrough.sh      # one member, one proposal, start to tally
```

Toolchain used: `nargo` 1.0.0-beta.26, `bb` 5.1.0, Foundry 1.4.4, Node 22.

## Tests

```bash
cd circuits/private_vote && nargo test    # 4  — circuit accepts/rejects
cd contracts && forge test                # 29 — tree, ballot logic, real proof
```

`contracts/test/HonkVerifier.t.sol` runs a proof produced by this repo's own
prover through the generated Solidity verifier, offline. Regenerate its fixture
with `node scripts/make-fixture.js` after any change to the circuit.

## If your shell injects NODE_OPTIONS

Some environments preload a Yarn PnP loader through `NODE_OPTIONS`, which hides
this project's `node_modules`. The shell scripts strip it; if you run a Node
script directly and see "isn't declared in your dependencies", use
`env -u NODE_OPTIONS node scripts/…`.
